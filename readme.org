* The Books of Everyone - a Magicians API

This API provides access to data related to the TV show "The Magicians," including episodes, characters, and quotes. It allows users to query information from TMDB and structure it within a local database for further use.

The endpoints are:

- /episodes - Get a list of episodes
- /episodes/:id - Get details of a specific episode
- /characters - Get a list of characters
- /characters/:id - Get details of a specific character
- /quotes - Get a list of quotes
- /quotes/:id - Get details of a specific quote
- /quotes/random - Get a random quote

** Current Status

The API is currently in the initial development stage. The database has been set up with initial data, and basic queries to TMDB are functional. Further work is needed to implement full RESTful endpoints and integrate them with the local database.
