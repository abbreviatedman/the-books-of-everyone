* The Books of Everyone - a Magicians API

This API provides access to data related to the TV show "The Magicians," including episodes, characters, and quotes. It allows users to query information from IMDB and structure it within a local database for further use.

The endpoints are:

- /episodes - Get a list of episodes
- /episodes/:id - Get details of a specific episode
- /characters - Get a list of characters
- /characters/:id - Get details of a specific character
- /quotes - Get a list of quotes
- /quotes/:id - Get details of a specific quote
- /quotes/random - Get a random quote

** Current Status

The API is currently in the initial development stage. The data for characters and episodes were scraped (see section on scraping) and saved as JSON.

** Data Pipeline and Scraper Documentation

*** Overview

The episodes and character data for Books of Everyone API is built initially from a scraping process that collects information from IMDb. Then the data was hand-corrected.

A Python scraper collected the episode and cast information from IMDb, transformed the data into the project's internal format, and output JSON files consumed by the API.

The primary generated artifacts are:

- =episodes.json=
- =characters.json=

*Note that this is how the data was /initially/ collected and has been further refined manually.* Running the scraper will overwrite any manual corrections, and it's up to the user to ensure that any manual edits are preserved if needed, possibly from this repository's data, or re-applied after scraping.

*** Source

The scraper collects information from IMDb for the television series associated with IMDb title ID =tt4254242=.

Data is retrieved from:

- IMDb season episode listings
- Individual IMDb episode pages
- Episode cast information exposed through IMDb pages

** Included Data

*** Episode Data

The dataset is intended to capture episode-level information including:

- season number
- episode number
- episode title
- episode identifiers
- associated cast information
- other metadata extracted from the episode page

*** Character Data

The dataset maintains a normalized collection of characters appearing throughout the series.

Character records are generated from episode cast data and consolidated across episodes whenever possible.

** Excluded Data

The scraper is not intended to collect:

- user reviews
- ratings
- trivia
- production notes
- external commentary
- non-canonical fan content

Only information necessary to support the API endpoints is considered in scope.

** Local Scraper Development Setup

*** Requirements

Python 3.10+ is recommended.

**** Python Dependencies

- requests
- beautifulsoup4

Install dependencies:

#+begin_src bash
pip install requests beautifulsoup4
#+end_src

Or create a =requirements.txt= containing:

#+begin_src text
beautifulsoup4
requests
#+end_src

and run:

#+begin_src bash
pip install -r requirements.txt
#+end_src

*** Running the Scraper

From the =data= directory:

#+begin_src bash
python scrape.py
#+end_src

The scraper will:

1. Visit each season listing on IMDb.
2. Discover individual episode URLs.
3. Process every episode.
4. Aggregate character information.
5. Build an episode dataset.
6. Write the updated JSON output files.

Generated files:

- characters.json
- episodes.json

**** Post Scraping Manual Changes

Examples:

The scraper provides the raw data needed to build the dataset, but some records may require normalization or manual review.

**** Known Data Quality Issues

The project currently tracks a number of post-processing and data-cleanup tasks.

Examples include:

- duplicate background character names
- inconsistent numbering schemes
- recurring unnamed character variants
- cast entries that may need consolidation
- cast entries that may need splitting

Examples currently under review include:

These issues are tracked in =notes.md=.

*** Limitations

**** IMDb Dependency

This scraper depends on IMDb's current HTML structure.

The scraper may require maintenance if IMDb changes:

- page layouts
- CSS structure
- cast list presentation
- URL patterns
- episode navigation

*** Rate Limiting

The scraper deliberately pauses between requests:

#+begin_src python
sleep(1)
#+end_src

This reduces request frequency and lowers the risk of overwhelming the source website.
